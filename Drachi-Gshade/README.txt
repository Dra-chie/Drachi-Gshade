～For those who downloaded this～

Thank you for downloading!
Please read the following instructions and usage methods carefully before using.

!!!! ・Please extract the downloaded archive to:
C:\Users\Public\GShade Custom Shaders\Shaders

You may place it in your usual folder if you prefer, but unexpected behavior may occur when GShade updates.

・Please use this shader pack with the latest version of GShade.
Using it with an older version of GShade may cause unexpected behavior.

・For proper operation, please turn OFF Performance Mode in GShade.

!!!! ・When using with FF14:
Go to System Configuration → Graphics Settings,
turn Dynamic Resolution OFF, and set Anti-Aliasing to FXAA.
(If these settings are not used, the rendering may look incorrect.)

!!!! ・The PSO2 shader presets were created assuming screenshots are taken using the Quick Menu’s “Fixed Camera” with the camera distance set close.
Because of this, screenshots may not work properly when using “Simple Screenshot.”
Thank you for your understanding.

It is also recommended to disable “Fur Rendering,” “Anti-Aliasing,” and any other settings that change the screen resolution.
